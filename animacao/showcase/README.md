# Vídeos com demonstrações do portfólio Zeey

Três narrativas novas geradas por código: Augusto Valença (site e confiança), Conversa (atendimento com contexto) e Nexo (pedido e aprovação). Usam imagens das demonstrações exibidas em zeeydigital.com.br e um mascote Z derivado do símbolo da marca. Essas marcas e telas são conceitos demonstrativos; o vídeo não as apresenta como clientes nem como resultados reais.

Na aba Actions, execute **Videos Zeey - portfolio animado** e baixe o artefato com três MP4. O workflow usa Remotion, Node, FFmpeg e Edge TTS. A renderização local foi testada; o workflow no GitHub ainda precisa ser validado.
